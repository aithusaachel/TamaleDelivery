# Staff & Admin Dashboard (Next.js / React)

Target: Desktop browsers for dispatchers and super admins.

### Key Features (v1)
- Secure staff login with MFA/2FA.
- Live operations overview: active deliveries, unassigned delivery alerts, active rider map.
- Phone/WhatsApp order creation: creates guest orders via `guest_contacts` without fake customer accounts.
- Rider document verification (approve / reject with required reason).
- Manual top-up approval/rejection and ledger auditing.
- Settings & pricing management (restricted to Super Admin).
