# Rider Mobile App (Flutter)

Target: Android (first release) & iOS
Design: High-contrast, large touch-target interface designed for motorbike/Moto King operations.

### Key Features (v1)
- Multi-step rider application (Ghana card, selfie, driving licence, vehicle details, MoMo number).
- Online / Offline toggle with backend eligibility check.
- Full-screen job offer with 30-second countdown ring and post-commission earnings display.
- Active delivery stages (Heading to Pickup -> Arrived at Pickup -> Picked Up -> Heading to Dropoff -> Arrived at Dropoff -> Enter Handover Code).
- Earnings & Ledger Wallet with manual top-up request submission.
