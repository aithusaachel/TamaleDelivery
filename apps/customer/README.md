# Customer Mobile App (Flutter)

Target: Android and iOS
Design: Uber & Bolt style 4-step booking flow tailored to Tamale identity.

### Key Features (v1)
- Phone OTP sign-in (+233 prefix).
- Pickup & Destination via Map Pin or Address Search (biased to Tamale).
- Vehicle selection: Motorbike vs Moto King with upfront quoted fare.
- Receiver details & "Who pays rider" selector (Sender or Receiver).
- Realtime order tracking with 4-digit handover code.
- Activity history and optional delivery rating.
